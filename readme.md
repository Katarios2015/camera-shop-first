## Проект 'Camera-shop'
Сайт(SPA) для магазина камер.
Проект реализован для проверки знаний в Акселераторе HTML Academy.
## Техническое задание
Необходимо реализовать функционал на следующих страницах:
Главная
- интерактивный слайдер с предложениями магазина,
- добавить товар в корзину из каталога
- каталог с карточками товаров
- фильтры: Тип камеры/Категория/Уровень/Цена
- сортировка: по алфавиту/по стоимости
- пагинация
- модальные окна в соответствии с макетом
Страница товара:
- кнопка "Добавить в корзину"
- слайдер с похожими товарами
- Отзывы:
- кнопка "показать больше" (работает по клику и по скроллу);
- валидация модального окна "Оставить свой отзыв",
- реализовать отправку отзыва
Страница корзины:
- рассчет итоговой стоимости
- удалить товар из корзины
- увеличить количество товаров
- применить промокод, перерасчет итоговой стоимости с учетом скидки
- кнопка "оформить заказ"

## Алгоритм запуска проекта
1. Установите зависимости, выполнив команду `npm install`.
2. Проверьте работу приложения, выполнив команду `npm start`.
